🎙️ Overview

HALPIS INTCM is a fully custom-built intercom system originally developed as a project at Arcada University of Applied Sciences. The project began over 6 years ago — [watch the original prototype](https://youtu.be/14hbYhLjQ8Y) — and has evolved through hundreds of hours of spare-time development.

At its core, HALPIS INTCM uses Raspberry Pi hardware with deeply integrated software built around Mumble, a low-latency, open-source voice chat system. It's designed to provide stable and clear communication in environments like workshops, multi-room setups, and media production spaces.

🔧 Features

    Custom-designed PCBs (Gerbers included)

    Ready for SMD component assembly

    3D-printable STL files for enclosures

    Raspberry Pi-based nodes for flexible deployment

    Integrated with Mumble for high-quality voice transmission

    90% of the software has been rewritten from scratch

📚 Background

The original version of HALPIS INTCM was successfully deployed in Arcada’s multi-camera workshops and served reliably for years. As time passed, both the software and hardware needed a full refresh.

This updated version is the result of:

    Rewriting nearly all the code (self-taught, so don’t expect perfection!)

    Learning KiCad and designing completely new PCBs

    Creating a more modular and maintainable system

    Spending many, many hours tinkering, testing, and refining
